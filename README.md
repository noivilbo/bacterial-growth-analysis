# Bacterial Growth Analysis

Exploratory data analysis of a synthetic bacterial growth dataset,
investigating population dynamics across different strains and
temperature conditions.


## Objective

The main objective is to explore how bacterial strain, temperature, and
time relate to population growth.

## Analysis

The project covers:

- Data quality and consistency assessment
- Missing and duplicate observations
- Temporal population dynamics
- Strain and temperature comparisons
- Strain × temperature interactions
- Population relative to carrying capacity

## Main Result

The analysis shows that the relationship between temperature and
population growth differs across strains. Each strain reaches its
highest observed population under a different temperature condition.

## Dataset

The dataset is synthetic and was created for data analysis and
statistical modelling practice. The results should therefore be
interpreted as an analytical exercise rather than evidence from real
biological experiments.
